# iMusic 视频上传功能使用指南

## 功能说明

iMusic 现在支持完整的视频上传功能，上传的视频会立即显示在首页。

## 上传流程

### 第一步：选择视频文件
- 点击"选择文件"按钮或拖拽视频文件到上传区域
- 支持的格式：MP4, WebM, Ogg
- 文件大小限制：最大 500MB
- 选择后会显示文件名和大小

### 第二步：填写视频信息
- **视频标题**（必填）：输入视频标题
- **视频描述**（可选）：描述你的演奏经历或感受
- **演奏者姓名**（必填）：你的名字
- **乐器类型**（必填）：选择使用的乐器
- **标签**（可选）：用逗号分隔，如：钢琴, 古典, 家庭

### 第三步：发布视频
- 点击"发布视频"按钮
- 系统会模拟 2 秒的上传过程
- 上传成功后会显示确认页面

## 技术实现

### 数据存储
- 使用浏览器 `localStorage` 存储视频数据
- 视频信息在刷新页面后仍然保留
- 支持多标签页数据同步

### API 端点
```
POST /api/videos - 添加新视频
GET /api/videos - 获取所有视频
```

### 数据流
```
用户上传 → 调用 API → 保存到 localStorage → 首页自动刷新
```

## 使用示例

### 方式 1：从首页上传
1. 访问首页 `http://localhost:3000`
2. 点击右上角"发布视频"按钮
3. 按照上传流程操作

### 方式 2：直接访问上传页
1. 访问 `http://localhost:3000/upload`
2. 按照上传流程操作

## 注意事项

1. **模拟上传**：当前版本使用模拟上传，视频文件不会真正上传到服务器
2. **数据持久化**：视频数据保存在浏览器本地，清除浏览器数据会丢失
3. **视频时长**：默认显示 "0:00"，实际项目中应该解析视频文件
4. **缩略图**：使用默认图片，实际项目中应该上传到云存储

2. **数据存储**：`lib/videoStore.ts`

4. **首页展示**：`app/page.tsx`
5. **数据管理**：`lib/data.ts`

### 重置数据

如果需要重置所有视频数据，可以在浏览器控制台执行：
```javascript
localStorage.removeItem('imusic_videos')
location.reload()
```

## 常见问题

### Q: 上传后看不到视频？
A: 请刷新页面或检查浏览器控制台是否有错误。

### Q: 如何删除已上传的视频？
A: 当前版本不支持删除功能，可以在浏览器控制台手动操作：
```javascript
const videos = JSON.parse(localStorage.getItem('imusic_videos'))
const newVideos = videos.filter(v => v.id !== '要删除的视频ID')
localStorage.setItem('imusic_videos', JSON.stringify(newVideos))
location.reload()
```

### Q: 数据会丢失吗？
A: 数据保存在 `localStorage` 中，清除浏览器数据或使用无痕模式会导致数据丢失。
