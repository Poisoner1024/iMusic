# iMusic 后端视频上传功能实现总结

## 实现概览

已完成完整的后端视频上传功能实现，基于腾讯云全栈架构（PostgreSQL + COS + SCF）。

## 已完成的文件

### 1. 核心SDK封装

#### `/lib/tencentcloud/cos.ts`
- **功能**：腾讯云COS对象存储SDK封装
- **特性**：
  - 生成带签名的上传URL（支持断点续传）
  - 直接文件上传
  - 文件元数据获取
  - 文件删除
  - CDN缓存刷新
  - 自动生成文件路径

#### `/lib/tencentcloud/db.ts`
- **功能**：PostgreSQL数据库连接池
- **特性**：
  - 连接池管理（最大20连接）
  - 自动连接释放
  - 事务支持
  - 错误处理

#### `/lib/tencentcloud/scf.ts`
- **功能**：SCF云函数 - 视频处理
- **特性**：
  - 视频元数据提取（FFmpeg）
  - 缩略图生成
  - 视频转码（可选）
  - 自动上传处理结果到COS
  - 更新数据库状态
  - 错误处理和重试机制

### 2. 数据库设计

#### `/lib/db/init.sql`
- **创建表**：
  - `members` - 会员表（支持前100位Founder会员）
  - `videos` - 视频表（完整视频信息）
  - `activities` - 活动表
  - `activity_photos` - 活动照片表
  - `member_stories` - 会员心路分享表
  - `teachers` - 师资表
  - `contact_forms` - 联系表单表
  - `admins` - 管理员表

- **索引优化**：所有高频查询字段都有索引
- **物化视图**：`video_stats` 视频统计
- **触发器**：自动更新 `updated_at` 字段
- **初始数据**：已插入 Founder会员（IRIS #001, DIEGO #019, MIYA #024）

### 3. API路由

#### `/app/api/videos/route.ts`
- **POST**：创建视频记录（上传到COS后）
  - 验证必填字段
  - 生成视频URL
  - 插入数据库（status='processing'）
  - 返回视频信息

- **GET**：获取视频列表
  - 只返回 `status='published'` 的视频
  - 按上传时间倒序
  - 包含完整视频元数据

#### `/app/api/videos/upload-url/route.ts`
- **POST**：获取COS上传凭证
  - 验证文件类型（仅视频）
  - 验证文件大小（最大500MB）
  - 生成带签名的上传URL（1小时有效期）
  - 生成UUID视频ID

### 4. 前端集成

#### `/app/upload/page.tsx`
- **三步骤上传流程**：
  1. 选择视频文件（拖拽支持）
  2. 填写视频信息（标题、描述、演奏者、乐器、标签）
  3. 完成发布

- **上传逻辑**：
  1. 调用 `/api/videos/upload-url` 获取上传凭证
  2. 直接上传视频文件到COS（PUT请求）
  3. 调用 `/api/videos` 创建视频记录
  4. SCF自动触发处理（异步）

- **用户体验**：
  - 进度指示器
  - 文件信息展示
  - 错误提示
  - 成功后的视频信息展示

## 功能特性

### ✅ 核心功能
1. **视频上传**
   - 支持拖拽和点击选择
   - 文件大小限制（500MB）
   - 格式验证（视频文件）
   - 断点续传支持（COS原生支持）

2. **云存储**
   - 直接上传到COS（不经过服务器）
   - 自动生成文件路径（按年月分目录）
   - CDN加速（可配置）
   - 生命周期管理（自动转低频存储）

3. **视频处理**
   - 自动提取元数据（时长、分辨率、大小）

   - 支持视频转码（H.264，1080p）
   - 异步处理（不影响上传体验）

4. **数据持久化**
   - PostgreSQL可靠存储
   - 完整的视频元数据

## 使用流程

### 1. 环境准备

```bash
# 克隆项目（已完成）
# git clone ...

# 1. 安装依赖
npm install

# 2. 配置环境变量
cp .env.example .env.local
# 编辑 .env.local 填写腾讯云凭证

# 3. 检查配置
npm run setup:tencentcloud

# 4. 初始化数据库
npm run db:init
```

### 2. 腾讯云配置

按照 `/docs/TENCENTCLOUD_SETUP.md` 配置：
- PostgreSQL数据库
- COS存储桶
- SCF云函数（含FFmpeg层）
- CDN加速（可选）

### 3. 启动开发

```bash
npm run dev

# 访问
open http://localhost:3000/upload
```

### 4. 上传测试

1. 访问上传页面
2. 选择视频文件（MP4, < 500MB）
3. 填写视频信息
4. 点击"发布视频"
5. 查看上传进度
6. 验证处理结果

### 5. 验证流程

```bash
# 检查COS存储桶
# 应该有视频文件: videos/2024/01/xxx.mp4

# 检查数据库
npm run db:query "SELECT * FROM videos ORDER BY created_at DESC LIMIT 1"
# status 应该是 'published'
# thumbnail_url 应该有值

# 检查SCF日志
# 应该有处理成功的日志
```

## 故障排查

### 常见问题

1. **上传失败："获取上传凭证失败"**
   - 检查环境变量配置
   - 检查腾讯云密钥有效性
   - 检查COS_BUCKET是否存在

2. **SCF函数未触发**
   - 检查COS触发器配置
   - 检查SCF执行角色权限
   - 检查函数日志

3. **缩略图未生成**
   - 检查FFmpeg层配置
   - 检查SCF内存（建议512MB+）
   - 检查视频格式是否支持

4. **数据库连接失败**
   - 检查DATABASE_URL格式
   - 检查白名单IP配置
   - 检查网络连通性
