## 1. 项目背景与概述

### 1.1 社团简介

IM公益声传社团（以下简称"IM"）由 IRIS 与 MIYA（会员号 001 & 024）联合发起，是一个以"公益（NO PROFIT）"为核心的亲子音乐社团。

- **使命：** 把音乐快乐带给每个家庭
- **愿景：** MUSIC HAPPY TO LIFE HAPPINESS
- **理念：** 言传不如身教，身教不如境教
- **价值观：** 向前一步

"IM" 具有双重含义：取自发起人 IRIS & MIYA 的首字母，同时寓意"我"——社团的每一位会员都是 IM 的主角和 leader，社团未来所有成就与荣誉归属于全体会员。

### 1.2 项目目标

建设一个线上官方网站，实现以下核心目标：

1. **展示社团形象**：向公众传递 IM 的使命、愿景与价值观
2. **会员招募**：吸引符合条件的亲子音乐家庭与专业音乐人士加入（前100位 Founder 会员）
3. **活动展示**：记录并展示公益授课、音乐活动、演出剪影等内容
4. **社区建设**：搭建会员分享、互动的线上社区平台
5. **品牌传播**：支持 IM 走向中国大陆、香港乃至全球的品牌扩展

## 2. 目标用户

### 2.1 主要用户群体

| 用户类型 | 描述 | 核心需求 |
|---|---|---|
| 亲子音乐家庭 | 希望陪伴孩子学习音乐、享受家庭音乐时光的家庭 | 了解社团、报名参与活动、查看课程 |
| 专业音乐人士 | 有教育情怀、愿意公益授课的音乐老师和演奏家 | 了解社团使命、申请成为师资会员 |

| 社会公众 | 对公益音乐活动感兴趣的普通访客 | 了解社团动态、观看演出内容 |
| 合作机构 | 福利机构、社区组织、学校等潜在合作方 | 了解合作方式、联系社团 |

## 3. 网站定位与设计原则

### 3.1 网站定位

> 温暖、真实、充满音乐感的公益家庭音乐社团官方主页

### 3.2 设计原则

- **温暖亲和**：以家庭、亲子、音乐为主视觉元素，传递温暖与快乐
- **简洁优雅**：参考社团 PPT 的简洁排版风格，避免过度设计
- **内容为王**：真实的活动照片、会员故事是核心内容
- **公益精神**：视觉上体现非营利、开放共享的社团文化
- **双语友好**：支持中英双语，为未来国际化扩展奠定基础

## 5. 功能需求详述

### 5.1 首页（Home）

**页面目标：** 第一时间传递社团核心精神，引导用户进一步了解或加入。

**功能模块：**

- **Hero 横幅区**
  - 全屏或半屏背景（活动照片轮播或视频背景）
  - 核心 Slogan：「把音乐快乐带给每个家庭」
  - 副标题：MUSIC HAPPY TO LIFE HAPPINESS
  - CTA 按钮：「了解社团」/ 「申请加入」

- **社团数字亮点栏**
  - 展示：会员数量、活动场次、公益课时数、覆盖城市等关键数据

- **社团理念简介区**
  - 使命、愿景、理念、价值观四个模块的卡片式展示

- **近期活动预告/回顾**
  - 最新 2-3 条活动动态卡片，含图片、标题、日期
  - 链接至「活动动态」页面

- **会员心声**
  - 轮播展示 3-5 条会员分享语录（含会员姓名和头像）

- **合作公益机构 Logo 墙**（未来扩展）

---

### 5.2 关于我们（About）

**功能模块：**

- **社团简介**
  - 图文并排排版，介绍 IM 的起源与核心定位
  - 强调"每位会员都是 IM 主角"的理念

- **创始人故事**
  - IRIS & MIYA 的个人介绍、创立初衷
  - 配演出现场照片

- **使命・愿景・价值观**
  - 视觉化展示四大核心：使命、愿景、理念、价值观

- **发展历程时间轴**
  - 社团成立、首批会员招募、首次公益活动、重要里程碑等

---

### 5.3 加入我们（Join Us）

**功能模块：**

- **Founder 会员介绍页**
  - 说明前100位 Founder 会员的特殊意义
  - 会员类型说明：亲子音乐家庭 / 专业音乐人士
  - 会员要求与权益

- **会员号选择功能**
  - 展示 1-100 号码网格，已被选择的号码置灰显示
  - 未选会员可选择自己喜欢的数字作为会员号

- **申请表单**
  - 字段：姓名、联系方式（微信/手机）、城市、家庭成员信息、擅长乐器、加入理由
  - 提交后自动发送确认通知

- **会员档案墙**
  - 已加入会员的卡片展示（含会员号、昵称、乐器、城市）
  - 隐私保护：仅展示会员授权公开的信息

---

### 5.4 活动动态（Activities）

**功能模块：**

- **活动列表页**
  - 支持按类型筛选：公益演出 / 音乐 Party / 公益授课 / 社区活动 / 国际交流
  - 支持按时间排序（最新 / 最早）
  - 卡片式展示：封面图、活动名称、日期、地点、简介

- **活动详情页**
  - 活动全文介绍
  - 相册展示（瀑布流或网格布局）
  - 参与会员展示
  - 分享功能（微信、朋友圈、复制链接）

- **活动报名功能**（针对未来活动）
  - 在线报名表单
  - 名额限制与状态显示（报名中 / 已满 / 已结束）

---

### 5.5 公益课堂（Classes）

**功能模块：**

- **课程介绍**
  - 吉他公益课详细介绍（课程目标、适合人群、课程安排）
  - 未来扩展其他乐器课程

- **师资介绍**
  - 公益师资团队成员卡片（照片、姓名、擅长乐器、简介）
  - 支持新增师资申请入口

- **课程报名**
  - 在线报名表单
  - 课程时间、地点展示

---

### 5.6 会员风采（Members）

**功能模块：**

- **心路分享专栏**
  - 会员投稿的文章/感言
  - 支持图文混排
  - 按发布时间排序，支持点赞

- **演出视频展示**
  - 家庭演奏视频（嵌入视频播放器）
  - 支持按乐器分类浏览：吉他、钢琴、小提琴、大提琴、中国乐器、合奏等

- **家庭乐团介绍**
  - 各家庭乐团的展示页面
  - 成员介绍、演奏风格、代表曲目

---

### 5.7 展望未来（Vision）

**功能模块：**

- **愿景路线图**
  - 图文展示 IM 未来规划：
    - 中西合奏交响乐团组建
    - IM 营地创办
    - 香港 (HK) 社团注册
    - IM 走向中国、香港、走向世界

- **进度展示**
  - 各项计划的当前进展状态标注

---

### 5.8 联系我们（Contact）

**功能模块：**

- **联系信息展示**
  - 微信公众号/社群二维码
  - 邮件联系方式

- **合作意向表单**
  - 适用于：福利机构、学校、社区组织等合作方
  - 字段：机构名称、联系人、联系方式、合作意向描述

## 6. 非功能需求

### 6.1 性能要求

- 首页加载时间 < 3秒（4G 网络环境）
- 图片自动压缩优化，支持 WebP 格式
- 视频采用懒加载策略

### 6.2 响应式适配

- **移动端优先（Mobile First）**：优先适配微信内置浏览器
- 断点适配：手机（< 768px）/ 平板（768px - 1024px）/ 桌面（> 1024px）

### 6.3 SEO 要求

- 页面标题、描述、关键词完整配置
- 语义化 HTML 结构
- 图片 Alt 文字
- Open Graph 标签（支持微信分享卡片效果）

### 6.4 安全要求

- 表单提交防 XSS、SQL 注入
- 会员隐私数据加密存储
- HTTPS 全站加密

### 6.5 可访问性

- 支持键盘导航
- 色彩对比度符合 WCAG AA 标准
- 图片提供替代文字

## 7. 视觉设计规范

### 7.1 品牌色彩

| 用途 | 颜色 | Hex |
|---|---|---|
| 主色（深红/酒红） | 品牌强调色，源自 PPT 分割线 | `#8B0000` 或 `#C0392B` |
| 辅色（深灰） | 文字、标题 | `#2C2C2C` |
| 背景色（浅灰白） | 页面背景 | `#F5F4F0` |
| 点缀色（金色） | 会员等级、特殊标注 | `#D4AF37` |

### 7.2 字体规范

- **中文标题：** 宋体 / 思源宋体（参考 PPT 风格）
- **中文正文：** 微软雅黑 / 思源黑体
- **英文：** Playfair Display（标题）/ Inter（正文）

### 7.3 视觉风格关键词

> 简洁 · 温暖 · 艺术感 · 真实 · 家庭温度

- 大量使用真实活动照片，避免过多图标插图
- 版式参考画廊风格：白色背景、大量留白、图片为主角
- 红色分割线作为视觉统一元素（延续 PPT 品牌识别）

## 8. 技术选型建议

### 8.1 前端技术栈

| 层次 | 推荐技术 | 理由 |
|---|---|---|
| 框架 | Next.js 14（App Router） | SEO 友好、SSR/SSG 支持、现有项目基础 |
| UI 样式 | Tailwind CSS | 已在 iMusic 项目中使用，快速开发 |
| 语言 | TypeScript | 类型安全，降低维护成本 |
| 动画 | Framer Motion | 流畅的页面动画和过渡效果 |
| 图片处理 | Next.js Image | 自动优化图片 |

### 8.2 后端与数据

| 层次 | 推荐技术 | 理由 |
|---|---|---|
| 数据库 | Supabase（PostgreSQL） | 开箱即用、含实时功能、免费额度够用 |
| 文件存储 | Supabase Storage / Cloudflare R2 | 活动照片、视频封面存储 |
| 认证 | Supabase Auth | 后台管理员登录 |
| 邮件服务 | Resend | 表单提交确认邮件 |

### 8.3 部署与运维

| 层次 | 推荐方案 |
|---|---|
| 部署平台 | Vercel（免费额度充足，适合 Next.js） |
| 域名 | 建议注册 `im-music.org` 或 `immusic.cn` |
| CDN | Vercel Edge Network（全球加速） |
