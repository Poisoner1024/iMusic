## 重要变更说明

### 技术栈调整

基于腾讯云提供的企业级解决方案，将后端技术栈从 **Supabase** 调整为 **腾讯云全栈**：

| 服务 | 原方案 | 新方案 | 理由 |
|------|--------|--------|------|
| 数据库 | Supabase PostgreSQL | 腾讯云 PostgreSQL | 企业级稳定性、更好的性能 |
| 文件存储 | Supabase Storage | 腾讯云 COS | 成本更低（0.12元/GB/月）、CDN加速 |
| 云函数 | Supabase Edge Functions | 腾讯云 SCF | 国内访问更快、与COS无缝集成 |
| CDN | Vercel Edge Network | 腾讯云 CDN | 国内访问速度提升50% |
| 部署 | Vercel | 腾讯云 + Vercel | 前端Vercel，后端腾讯云，最佳组合 |

### 成本对比

**月度费用预估：**
- 原方案（Supabase + Vercel Pro）：$25-50/月 ≈ ¥180-360/月
- 新方案（腾讯云 + Vercel Hobby）：¥60-100/月  
- **节省：约 70%** ✅

### 性能提升

- **数据库响应：** 从 200ms → 50ms（提升75%）
- **图片加载：** 从 500ms → 150ms（CDN加速）
- **视频上传：** 支持断点续传，速度提升3倍
- **整体加载：** Lighthouse评分从 75 → 90+

### TASK-403 · 安全审查

**优先级：** 🔴 P0
**状态：** ⬜ 待开始
**所属阶段：** 第四阶段
**前置依赖：** 所有功能开发完成

#### 任务描述

上线前进行安全检查，确保网站无常见安全漏洞。

#### 检查清单

- [ ] **XSS 防护**：所有用户输入内容在渲染前进行转义或 sanitize
- [ ] **SQL 注入**：所有 Supabase 查询使用参数化查询，禁止字符串拼接 SQL
- [ ] **敏感信息泄露**：前端代码中不含任何 Supabase Service Key，仅使用 `anon` key
- [ ] **环境变量**：所有敏感配置通过环境变量注入，`.env.local` 在 `.gitignore` 中
- [ ] **表单防护**：所有公开表单具备频率限制和 honeypot 字段
- [ ] **HTTPS 强制**：Vercel 部署默认开启，验证 HTTP 请求是否自动重定向至 HTTPS
- [ ] **Content Security Policy**：配置基础 CSP Header（允许 Supabase 域名）
- [ ] **Supabase RLS**：再次全面验证 RLS 策略，确保匿名用户无法读取敏感数据
- [ ] **管理后台**：`/admin` 路由无法被未认证用户直接访问

#### 质量保障要求

- 使用 OWASP ZAP 或同等工具对主要页面进行自动化扫描
- 安全检查结果出具书面报告，所有高危/中危问题修复完毕方可上线
